# FIT ATLAS

Public deployment of the FIT ATLAS clothing recommendation prototype.

Website: https://jidamlee.github.io/capstone2-web/

GitHub Pages serves the committed `docs/` directory from `main`. This repository contains only public web assets and the derived catalog snapshot.

The catalog contains 1,150 tops from H&M, Musinsa and Zigzag, with approved cover photographs for 1,071 products. Classification uses provisional style rules; scores are not probabilities or validated fit measurements.
